Шаг 1. Карточки-перевёртыши

Главная страница показывает 12 системных папок с английскими словами. Кликните по карточке — она перевернётся и покажет английское слово с примером употребления.

Так работает принцип активного вспоминания: мозг сначала пытается вспомнить перевод, и лишь потом проверяет себя.

🔊

Шаг 2. Озвучка и режим повторения

В режиме повторения есть кнопка 🔊 — браузер произнесёт английское слово вслух через Web Speech API. Так работает зрительно-слуховое двойное кодирование.

Запустите повторение кнопкой «🎓 Повторение» вверху или «Повторить группу» в заголовке секции.

📥

Шаг 3. Импорт словаря

Кнопка «📥 Импорт» позволяет загрузить реальные словари SMARTool (A1–B2) или простой CSV/TXT. Поддерживается пять режимов раскладки по группам.

👁️

Шаг 4. Режим для слабовидящих

Кнопка 👁️ вверху или в левом меню включает контрастную тему с увеличенным шрифтом и отключёнными анимациями.

📲

Шаг 5. Установка на телефон

ETT — это PWA (прогрессивное веб-приложение). На телефоне откройте меню браузера и нажмите «Установить приложение» или «Добавить на главный экран».

После установки ETT работает как обычное приложение: иконка на рабочем столе, запуск без адресной строки, работа офлайн.

ℹ️ О проекте

English Today and Tomorrow (ETT) — бесплатное веб-приложение для изучения английской лексики методом визуальных ассоциаций.

Слоган: «Учи сегодня — говори завтра».

В основе приложения лежат три принципа памяти: двойное кодирование Пайвио (слово + картинка), активное вспоминание (карточки-перевёртыши) и интервальное повторение (режим самопроверки по группам).

Приложение полностью работает в браузере: без бэкенда, без библиотек, без регистрации. Все данные хранятся локально через LocalStorage. Внешний запрос — только к API Unsplash для подбора картинок.

  • 12 системных папок × 12 слов = 144 единицы лексики в комплекте.
  • Создавайте свои папки и слова, редактируйте существующие.
  • Импортируйте реальные словари SMARTool (A1–B2) и Mueller.
  • Режим повторения с прогресс-баром и статистикой.
  • Озвучка английских слов через Web Speech API.
  • Тёмная тема и режим для слабовидящих.
  • PWA: устанавливается на телефон, работает офлайн.
  • Левое меню быстрой навигации и горячие клавиши.
